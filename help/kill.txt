kill: signal processes

  kill [-s signal | -signal] pid...
  kill -l

Sends each process (by ID: see ps) a signal: TERM (the default), INT or HUP are Ctrl+T for it (a terminate event: most programs stop, and one that catches it can tidy up first); KILL ends it at once; 0 only checks it's there.  A signal is a name (TERM, SIGTERM) or its number (15, 9, 2, 1, 0).  -l lists them.  Process 1 is init itself.  Needs init (`help init`); ccsh's own kill also takes %job. Exit status 1 if any process couldn't be signalled.
