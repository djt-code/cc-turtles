git: minimal git client for CC:Tweaked

Clones and pulls a single branch over HTTP using the hosting server's REST API (Forgejo/Gitea or GitHub) instead of the git wire protocol, so there are no packfiles to decode.  Tracks the commit and blob SHAs of what it checked out in .gitlite, and on pull only downloads blobs whose SHA changed, deletes tracked files removed upstream, and never touches untracked files.

A computer's disk is small (1 MB by default), so a clone leaves out what the device doesn't run: sim/ always, pc/ on a turtle and turtle/ on a computer.  --skip <dir> leaves out more, --all nothing, and --only <path> (a file, or a folder ending in /) takes just those; the choice is kept in .gitlite and pull keeps to it (a checkout from before this gets the device's rule on its next pull, and loses those folders).  If the disk fills anyway it stops, keeping what it got, and `git pull` carries on once there's room. The same options on pull change the choice (deploy/setup uses --only to put just the apps you name on a device).

Usage:
  git clone <url> [dir] [-b <branch>] [--token <token>] [--skip <dir>]... [--only <path>]... [--all]
  git pull   [dir] [--skip <dir>]... [--only <path>]... [--all]
  git status [dir]
  git log    [dir] [-n <count>]

  <url> is the repo's web URL, with or without .git:
    https://git.example.com/me/cc-turtles
    https://github.com/mepholic/cc-turtles.git

Bootstrap onto a turtle or computer: deploy/setup.lua does it all;
  wget run https://raw.githubusercontent.com/djt-code/cc-turtles/main/deploy/setup.lua

--token is only needed for private repos (Forgejo access token or GitHub PAT); it is saved in .gitlite so pull can reuse it.
