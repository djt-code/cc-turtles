traceroute: the routers on the way to a host

  traceroute [-n] [-m hops] [-q queries] [-w seconds] host

Sends echo requests with a TTL of 1, then 2, and so on (up to -m, 30): each router on the way drops the one whose TTL runs out there and says so (ICMP time exceeded), so each line is the next hop: its address and how long each of -q (3) tries took, "*" for one with no answer in -w (2) seconds.  A hop with a name (lib/netdb: `ip host`, else DNS's PTR record) shows it with the address in brackets; -n: addresses alone, no lookups for the hops.  host is an address or a name.  It stops at the host (its echo reply), or at "!N" (a router has no route on), "!H" (no ARP answer: no such host on the last network), "!X" (administratively prohibited: a filter, such as a Network Gateway in NAT mode, which carries no ping past it) or "!P".  Exit status 0 if it got to the host, 1 if not, 2 for trouble.
