fileserver: the disks in every attached disk drive as one folder

Usage:
  fileserver
      what's in the pool: each disk, its space, the total
  fileserver mount
      put the pool at /jbod (in this computer's fs, for every program, until it reboots)
  fileserver add <drive>
      make a disk that has files on it part of the pool (its files join the pool where they are)
  fileserver startup
      mount it at every boot (adds a line to startup)

Disk drives count whether they're beside the computer or on wired modems (right-click each drive's modem to connect it: `peripherals` lists them as drive_0, drive_1...).  A blank floppy put in any of them joins the pool by itself (labelled "jbod"), so /jbod grows as drives and disks are added; a disk with files on it waits for `fileserver add`. Folders are shared across the disks; each file goes on the disk with the most room, and one too big for any single disk is split across several. A floppy holds 125 KB (the server's floppy_space_limit), less 500 bytes for each file and folder.  Take a disk out and its files go with it until it's back (a split file needs all its disks).  The layer lives in lib/jbod.lua.
