echo: write its arguments to standard output (POSIX/XSI echo)

  echo [string...]

Writes the strings separated by single spaces, then a newline.  There are no options: -n and -- are printed like any other string.  The XSI escapes are understood: \a \b \f \n \r \t \v, \\ a backslash, \0num a character by its octal code (up to 3 digits), and \c, which stops the output there with no newline.  Any other backslash is written as is.

CraftOS extension: its shell has no redirects, so echo does them:
  echo some text > notes.txt
      writes the file (replacing it)
  echo more text >> notes.txt
      adds a line to the end
(">file" attached works too; the last one given wins.)  The shell splits words on spaces and strips double quotes, so a quoted phrase becomes one argument; use single quotes for Lua strings:
  echo shell.run('autocompost') > /startup.lua
Under Craftix (_G.POSIX_SH set) the shell does the redirects, and a > that reaches echo was quoted: it's printed like any other string.
