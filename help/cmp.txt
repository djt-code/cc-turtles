cmp: compare two files byte by byte (POSIX cmp)

  cmp [-l|-s] file1 file2

Says nothing and exits 0 when the files are the same.  Otherwise it writes "file1 file2 differ: char N, line L" for the first byte that differs and exits 1.  -l lists every differing byte instead, as its position (decimal) and the two bytes (octal); -s writes nothing and only the status tells.  When one file is the start of the other, "cmp: EOF on <shorter>" goes to the error output (status 1).  Either file can be "-", standard input.  A file that can't be read: status 2.
