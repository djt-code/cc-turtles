env: show the environment, or run a command in a changed one

  env [-i] [-u name]... [name=value]... [command [arg...]]

With no command, writes the environment, a name=value line for each variable, sorted by name.  With one, runs it with the environment changed for it alone: -i starts from an empty one, -u name takes name out, name=value sets it.  The environment is what a program reads with os.getenv(name): under ccsh, the exported variables (export, and X=1 cmd; PS1 is one), PATH, PWD and HOSTNAME.  CraftOS itself has none: outside ccsh env says so. Exit status: the command's, 127 if it isn't found; 125 for env's own errors.
